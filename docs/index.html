Ingenieria de Rendimiento y Navegacion

Capacidades Tecnicas Disenadas para Conduccion Continua

Cada modulo del servidor .NET 10 y de la app Jetpack Compose opera sin asignaciones redundantes en tiempo real, manteniendo fluidez estable en rutas transcontinentales.

Motor 2D/3D Hardware (60-120 FPS)

Proyeccion pinhole 3D con recorte estricto en plano cercano (rz >= 0, minDepth = 8f), pools estaticos RoadSegPool3D y RouteSegPool3D sin GC, 3 temas STY (DARK_PREMIUM, HIGH_CONTRAST, CYBER_NEON) y zoom dinamico por velocidad (0.85x a 1.20x).

rz >= 0 0 bytes GC 3 temas STY

Enrutador A* Transcontinental

AStarRouter pondera limites de velocidad, jerarquia vial, semaforos y giros en U con limite de 500,000 pasos. Incluye snapToRoad por rumbo, recalculo automatico hacia adelante ante desvios y deteccion real de sentido contrario sin falsos positivos.

500,000 pasos Wrong-Way Forward Snap

Caminos Ocultos y Atajos Secretos

Deteccion y extraccion dedicada de vias secretas SCS (RoadType = 5 / HiddenSecretRoad). Se renderizan en ambar discontinuo de alto contraste tanto en vista 2D como 3D y muestran insignia propia en la tarjeta TurnByTurnCard.

RoadType = 5 Ambar #F59E0B TurnByTurnCard

Panel de Carriles, Voz TTS y Bitacora

Asistente visual de carriles JunctionView con posicion lateral en vivo e intermitentes, guia hablada TTS en hitos (1000 m, 500 m, 200 m, 50 m), alertas de velocidad/combustible/fatiga y registro persistente en TripLogScreen.

JunctionView TTS Turn-by-Turn TripLogScreen

Extraccion Cartografica Local

AtsGpsServer --build-map escanea tus archivos base_map*.scs y dlc_*.scs mediante HashFS, generando polilineas por interpolacion lineal de 5 puntos (Vector3.Lerp) en formato binario ATSMAP03 v3 de forma atomica. map_ats.bin nunca se redistribuye.

--build-map Vector3.Lerp x5 ATSMAP03 v3

Endurecimiento Local Verificado

Modelo de Seguridad y Matriz de 9 Endpoints

Aislamiento estricto para red privada local con validacion de cabeceras, bloqueo por IP y 48/48 pruebas de seguridad automatizadas dentro de la suite de 125/125 pruebas xUnit.

Bloqueo Origin (403)

RequestSecurityMiddleware rechaza con 403 Forbidden cualquier peticion HTTP o WebSocket que incluya el encabezado Origin (incluido localhost), neutralizando llamadas desde navegadores y ataques CSRF.

Guardia Host e IP Privada

Acepta unicamente localhost, loopback (127.0.0.0/8, ::1), IPv4 privada RFC 1918 (10/8, 172.16/12, 192.168/16) e IPv6 link-local/ULA. IpWhitelistMiddleware bloquea IPs publicas.

PIN Obligatorio + Bloqueo 429

POST /api/pair exige PIN de 6 digitos (CSPRNG) sin exenciones USB ni localhost. Comparacion en tiempo constante y bloqueo por IP (429 + Retry-After durante 2 min tras 5 fallos).

Bearer 48h + Pre-Handshake

Token criptografico de 32 bytes vigente 48 h (AuthTokenStore). En /ws/telemetry, el token se valida antes de ejecutar AcceptWebSocketAsync(), devolviendo HTTP 401 si es invalido.

Despliegue y Compilacion

Instalacion y Compilacion desde Fuentes

Requisitos: Windows 10/11 x64 con .NET 10.0, American Truck Simulator (scs-telemetry.dll en bin\win_x64\plugins\) y Android 8.0+ en la misma LAN privada.

PowerShell · Generacion local de mapa y arranque en Windows 
# 1. Extraer grafo binario local map_ats.bin (ATSMAP03 v3) desde tus .scs
dotnet run --project server -- --build-map

# 2. Iniciar lanzador grafico WPF en puerto TCP 35500 (o usar Iniciar_Servidor.bat)
.\Iniciar_Servidor.exe

El instalador Setup (Instalador_AtsGps_v1.4.2_Setup.exe) automatiza la deteccion de Steam/ATS, presenta NOTICE, LICENSES.md y LICENSE en el Paso 1, configura la regla de firewall privada en TCP 35500 y ejecuta AtsGpsServer.exe --build-map localmente sin redistribuir datos del juego.

PowerShell · Compilacion, 125 pruebas xUnit y publicacion limpia del servidor 
# Compilar servidor .NET 10 en Release
dotnet build server/AtsGpsServer.csproj -c Release

# Ejecutar suite completa (125/125 pruebas, incluidas 48/48 de seguridad)
dotnet test tests/AtsGpsServer.Tests/AtsGpsServer.Tests.csproj

# Publicar sin simbolos .pdb ni ensamblados innecesarios
dotnet publish server/AtsGpsServer.csproj -c Release -o server/publish -p:DebugType=None -p:DebugSymbols=false
PowerShell · Compilacion y publicacion single-file del lanzador WPF 
# Compilar proyecto WPF AtsGpsLauncher
dotnet build tools/AtsGpsLauncher/AtsGpsLauncher.csproj -c Release

# Publicar ejecutable unico win-x64 sin .pdb
dotnet publish tools/AtsGpsLauncher/AtsGpsLauncher.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=None -p:DebugSymbols=false -o tools/AtsGpsLauncher/singlefile
PowerShell · Compilacion del cliente Android (Kotlin 2.1.0 + Jetpack Compose) 
cd android
.\gradlew.bat compileDebugKotlin assembleRelease --console=plain

Artefacto oficial resultante: apks/AtsGpsApp_v1.4.2.apk (version 1.4.2, versionCode = 17). La sesion se persiste en el dispositivo por 48 horas mediante AuthTokenStore.

PowerShell · Tunel opcional por cable USB (la conexion Wi-Fi no requiere ADB) 
# Con depuracion USB activa en Android y Google Android SDK Platform-Tools instalado:
adb reverse tcp:35500 tcp:35500

Google Android SDK Platform-Tools (Apache 2.0) no se redistribuye en el repositorio ni en el instalador. Puede descargarse desde developer.android.com/tools/releases/platform-tools y colocarse junto a Iniciar_Servidor.exe o en %LOCALAPPDATA%\Android\Sdk\platform-tools. El PIN de 6 digitos sigue siendo obligatorio por USB.

Los ejecutables Windows (Instalador_AtsGps_v1.4.2_Setup.exe e Iniciar_Servidor.exe) se compilan actualmente sin certificado comercial Authenticode, por lo que Windows Defender SmartScreen puede mostrar "Windows protegio su PC" al abrirlos por primera vez. La distribucion publica del instalador permanece retenida hasta completar la revision y aprobacion formal de PROVENANCE.md.
